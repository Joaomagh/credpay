Especificação Técnica para Frontend Angular

01. Tokens e Paleta

Uso obrigatório das cores institucionais:

  • #00685f / #0D9488 : Primária / Ação teal
  • #0B1C30 / #0F172A : Superfície grafite
  • #047857 / #D1FAE5 : Status Aprovada
  • #B45309 / #FEF3C7 : Status Pendente
  • #B91C1C / #FEE2E2 : Status Rejeitada
  • #881337 / #FFE4E6 : Status Falhou
02. Acessibilidade WCAG 2.1 AA

Regras de conformidade obrigatórias nos templates:

  • • Informação multifatorial: Nunca depender exclusivamente da cor para status; obrigatório combinar ícone + rótulo textual explícito.
  • • Live Region: Anunciar estados assíncronos (carregamento e erro) via aria-live="polite".
  • • Foco: Anéis de foco contrastantes em 2px para navegação via teclado tab.
03. Contrato de Dados (DTO)

Estrutura canônica estrita para o componente de resposta: 

interface TransactionResponse {
  valor: number;
  moeda: 'BRL';
  status: 'PENDENTE' |
          'APROVADA' |
          'REJEITADA' |
          'FALHOU';
}
